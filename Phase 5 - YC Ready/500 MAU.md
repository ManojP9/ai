# 500+ Monthly Active Users

**Why**: 500 MAU is the minimum credible user number for a YC application in consumer. Below that it reads as "friends and family."

## How to Get There

- Referral system ([[Referral System]]) — each user brings 1–2 more
- Shareable lists ([[Shareable Lists]]) — social content drives organic signups
- City leaderboard SEO ([[City Leaderboards]]) — search traffic
- Weekly digest ([[Weekly Digest]]) — re-activates churned users

## Tracking

- PostHog monthly cohort report
- MAU definition: visited app + performed ≥1 search in the last 30 days
