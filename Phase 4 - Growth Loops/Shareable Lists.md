# Shareable Food Lists

**Why**: User-generated lists are SEO content and social distribution at zero cost. "My top 5 Italian spots in NYC" shared on Instagram is an acquisition funnel.

## Implementation Plan

- `/lists/[id]` public page
- Users curate a named list from their favorites
- Each list has a public URL + Open Graph preview image
- Share to Twitter/Instagram/WhatsApp via Web Share API
