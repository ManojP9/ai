# AI Baby Companion — App Factory Package

Generated by the AiNa App Factory from the existing **AI Baby Companion** project, used as the PRD/brief. The headline deliverable is the **document set** in `docs/`; a working, verified parent-console codebase ships alongside in `app/`.

## What this is

A screen-free, voice-first AI companion toy for ages 3–7 (ESP32-S3 hardware + cloud voice loop), governed by a **parent console** where consent, conversation history, personality, and data rights are first-class — because the product records a child's voice, COPPA/GDPR-K compliance is load-bearing.

## Code (`app/`)

FastAPI + HTMX **Parent Console** (golden stack, no client build step). Manages children, consent-gated conversation review, personality, audit, and data export/erasure.

```bash
cd app
python3 -m venv .venv && . .venv/bin/activate   # requires python3-venv
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000        # http://127.0.0.1:8000
```

Verified by actually running it — see the verification table in [dev-notes](docs/04-dev-notes.md). The consent gate (403 without consent/mic), export (decrypted), erasure, retention, and OTA manifest all pass.

## Stack

Python 3.12 · FastAPI · Jinja2 + HTMX · Postgres (in-memory in this scaffold) · Docker on VPS.

## Before production

This scaffold deliberately stubs **auth, AES-256-GCM at rest, and verifiable consent**. See the conditions in [security](docs/05-security.md) and the go-live checklist in [ops-runbook](docs/09-ops-runbook.md). A children's product also needs legal sign-off — the docs are not legal advice.
