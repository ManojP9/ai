---

## Working rules (Karpathy guidelines)

Apply these to any change in this directory:

1. **Think before coding** — state assumptions, surface ambiguity, suggest simpler alternatives instead of deciding silently.
2. **Simplicity first** — minimal code for the actual request; no unrequested features, abstractions, or flexibility.
3. **Surgical changes** — touch only what the task needs; match existing style; don't refactor working code or remove unrelated dead code.
4. **Goal-driven execution** — turn the request into testable success criteria; write a brief plan and verify it.
